HAPPY BIRTHDAY GREETING
=======================

1. Put her pictures in the  photos  folder (jpg, png, webp, gif).
2. Put your song(s) in the  music  folder (mp3, m4a, ogg, wav).
3. Open  config.json  and change: name, from, title, subtitle, message.
   Optional photo captions:  "captions": { "pic1.jpg": "Our first trip!" }
4. Run:   python app.py
   It opens in your browser. On a phone on the same Wi-Fi, use the
   "On phone" link printed in the terminal.

Greetings typed on the page are saved in  wishes.json.
